# اختبارات قواعد أمان Firestore

هذه الحزمة تتحقق تلقائياً من أن قواعد الأمان في `firestore.rules` تمنح كل دور
ما يخصّه فقط (المالك، مُدخِل اليوميات، المدير المالي، المدير العام…)، وتمنع
المستخدم الموقوف أو المجهول، قبل أي نشر.

## ماذا تفحص؟

- **الأيام (days):** القراءة لكل مستخدم فعّال، والكتابة للمالك ومُدخِل اليوميات فقط.
- **الإعدادات (meta):** الكتابة للمالك فقط، والقراءة للفعّالين.
- **الأدوار (roles):** الإنشاء/الحذف للمالك، والمستخدم يحدّث «آخر دخول» فقط دون ترقية نفسه.
- **سجل النشاط (activity):** الإنشاء لكل فعّال، والتعديل/الحذف للمالك فقط.
- **الاعتمادات (approvals):** الكتابة للمالك والمدير المالي ومُدخِل اليوميات، والعام يقرأ فقط.
- **المستخدم الموقوف والمجهول:** ممنوعان.
- **أي مجموعة أخرى:** ممنوعة تماماً.

## التشغيل في GitHub (تلقائي)

يعمل الفحص تلقائياً عند كل تعديل على `firestore.rules` عبر
`.github/workflows/firestore-rules.yml`. إن فشل أي اختبار تظهر علامة ❌ على
العملية في GitHub، فتعرف أن القواعد فيها ثغرة قبل نشرها.

## التشغيل محلياً (اختياري لمن يريد)

يتطلب Node.js وJava.

```bash
cd firestore-tests
npm ci
npm test
```

يقوم الأمر بتشغيل محاكي Firestore، تحميل `../firestore.rules`، ثم تنفيذ
كل الاختبارات وإظهار النتيجة.
